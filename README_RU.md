# RF Measurement Tools v1.8 — PWA / Web App

Это самостоятельная устанавливаемая веб-версия **утверждённой RF Power Meter v1.8**. Инженерные алгоритмы и две вкладки v1.8 не изменены. Версия v1.9 не используется.

## Содержимое

- `index.html` — интерфейс и все расчёты v1.8, дополненные только интерфейсом установки.
- `manifest.webmanifest` — название, оформление и параметры установки.
- `sw.js` — сервисный работник для автономного запуска после первой загрузки.
- `icons/` — иконки приложения для Android, iOS и компьютеров.

## Как опубликовать

1. Распакуйте ZIP.
2. Загрузите содержимое папки (не только файл `index.html`) в корень сайта или отдельный каталог на HTTPS-хостинге: Netlify, Cloudflare Pages, GitHub Pages или собственный веб-сервер.
3. Откройте HTTPS-адрес в браузере при включённом интернете хотя бы один раз.
4. Нажмите `УСТАНОВИТЬ`, либо воспользуйтесь меню браузера.

**Android / Chrome:** меню ⋮ → «Установить приложение» или «Добавить на главный экран».

**iPhone / Safari:** «Поделиться» → «На экран Домой» → «Добавить».

**Desktop Chrome / Edge:** значок установки в адресной строке или пункт установки в меню.

Для локальной разработки можно использовать localhost: `python -m http.server 8000` внутри папки; затем открыть `http://localhost:8000/`.

## Важно

- Если просто открыть `index.html` двойным щелчком (file://), инженерные функции работают, но PWA-установка и Service Worker недоступны. Для них требуется HTTPS или localhost.
- После первого успешного кэширования интерфейс и все расчёты работают офлайн. Внешние нормативные ссылки ETSI в офлайн-режиме недоступны.
- Расчёты RF Spectrum / Constellation являются модельными, не измерительными.
- Установка зависит от браузера и настроек устройства. Постоянный публичный URL в пакет не включён: публикация на хостинге выполняется отдельно.
- Пакет не передаёт введённые параметры на сервер, не содержит CDN, аналитики или внешних библиотек.
