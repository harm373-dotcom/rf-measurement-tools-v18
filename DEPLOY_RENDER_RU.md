# RF Measurement Tools v1.8 — публикация через Render

Этот пакет содержит PWA на базе утверждённой v1.8 и конфигурацию Render.

## Публикация
1. Создайте отдельный репозиторий GitHub (например, `rf-measurement-tools-v18`).
2. Распакуйте ZIP и загрузите **содержимое папки** в корень репозитория; `index.html`, `sw.js`, `render.yaml` должны находиться на одном уровне.
3. В Render откройте New → Blueprint, подключите репозиторий и подтвердите `render.yaml`. Или New → Static Site, выберите репозиторий, настройте Build Command по `render.yaml` и Publish Directory `public`.
4. После статуса Live откройте HTTPS-адрес Render в браузере.
5. Проверьте навигацию, конвертацию мощности, спектр, манифест и установку PWA; затем отключите интернет и перезапустите установленное приложение.

## Замечания
- Исходный HTML v1.8 не изменяется этим пакетом; добавлены только файлы публикации.
- Offline-кэш активируется после загрузки по HTTPS и успешной установки service worker. Перед проверкой дождитесь первой полной загрузки.
- Реальное развертывание и проверка установки должны выполняться на публичном HTTPS-адресе, а не из локального `file://`.
